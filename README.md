Este proyecto es acerca de una app movil multiplataforma sobre el cual 
se busca crear comunidades de manera instantanea , con intereses en comun
y sobre todo en universidades , se utiliza el estilo tradicional "match" y 
"swipe" para aprobar o rechazar si realmente el usuario que esta enfrente 
te podria servir como compañero , socio o simplemente amigo.
